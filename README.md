# SMART AGRICULTURE ANALYTICS AND CROP RECOMMENDATION SYSTEM

##  Project Overview

Developed a **Smart Agriculture Analytics** project that combines 
**Data Analytics and Machine Learning** to support agricultural 
decision-making.

The project consists of two main modules:
1. **Crop Recommendation System** – Developed using Python, Machine Learning and Streamlit.
2. **Crop Production Analytics Dashboard** – Developed using Microsoft Power BI.



##  PART 1: CROP RECOMMENDATION SYSTEM

Developed an interactive crop recommendation application using 
**Python, Machine Learning, and Streamlit**.

### Key Features
- Recommends suitable crops based on soil and environmental conditions.
- Uses Nitrogen (N), Phosphorus (P), and Potassium (K) values.
- Considers temperature, humidity, pH, and rainfall.
- Uses a trained Machine Learning model to predict suitable crops.
- Provides an interactive interface through Streamlit.

**Dataset:**  `Crop Recommendation.csv` (Kaggle)



## PART 2: CROP PRODUCTION ANALYTICS DASHBOARD

Developed an interactive **Power BI Dashboard** to analyze 
agricultural crop production across different states and seasons in India.

### Key Features
- Total Crop Production Analysis
- State-wise Production Analysis
- Top 10 Crops by Production
- Year-wise Production Trends
- Season-wise Production Analysis
- Interactive Filters for State, Crop, Year, and Season

**Dataset:** `Crop Production.csv` (Kaggle)

- Analyze agricultural crop production patterns across India.
- Identify major crop-producing states and crops.
